Set up video downloads

A quick one-time setup lets the extension download external videos (YouTube/Vimeo) and save to any folder.

Checking...
1

Download the installer

Click the button below to download the setup executable. Save it somewhere convenient.

2

Run the installer

Double-click "PatreonArchiverBridge_Setup.exe". A wizard opens; select the installation path and click "Install". Optionally check "Download yt-dlp" to get the video engine. Then fully restart Chrome (close all windows).

Note: If Windows Defender SmartScreen appears, click "More info" and then "Run anyway" to proceed.

3

Done!

Once the status banner at the top turns green, everything works automatically. Choose a download folder in Settings, then click "Download" on any post.
